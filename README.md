ps55utils
=======
このプロジェクトはIBM 5550およびPS/55コンピューター用の以下のユーティリティーを含みます。

* GETBIO55 - PS/55（MCA機）において、システムボードのROM (BIOS ROM) をダンプし、バイナリーファイルとして出力します。
* GETFPS5 - PS/55（MCA機）において、ディスプレイ・アダプターのフォントROMをダンプし、バイナリーファイルとして出力します。
* DCBPATCH - 日本語DOSのディスプレイ構成ブロックをパッチしてグラフィック支援機能を無効にします。エミュレーターでグラフィックを使うプログラムが正常に動作しない場合は、これを試して下さい。
* GETK55 - マルチステーション5550およびPS/55（5550機）において、漢字フォントカードのROMをダンプし、バイナリーファイルとして出力します。

### 使い方

#### DCBPATCH

IBM 日本語DOS バージョンK3.3, IBM DOS バージョン J4.0, J5.0の日本語モード（PS/55モード）で動作します。

DOSプロンプトで`DCBPATCH`を実行して下さい。

また、`DCBPATCH F`を実行するとINT 10H, AH=00h（画面モードのセット）をフックして常駐します。画面モードが途中で変わるアプリケーションを使用する場合に有効です。

#### GETBIO55

PS/55（MCA機）において、PC DOS 3.3以降やIBM DOS バージョン J4.0以降の英語モード（PS/2モード）で動作します。HIMEM.SYSなどのメモリ管理ドライバーが導入されていると正しいデータを取得できないため、CONFIG.SYSを編集してその行を削除して下さい。

DOSプロンプトで`GETBIO55`を実行して下さい。ダンプされたBIOS ROMデータはSYSBIOS.BINというファイル名で出力されます。

#### GETFPS5

PS/55（MCA機）において、IBM 日本語DOS バージョンK3.3, IBM DOS バージョン J4.0, J5.0の日本語モード（PS/55モード）で動作します。DOS/V（日本語）やPC DOS（英語）でも動作します（一部のメッセージが表示されない制限があります）。

DOSプロンプトで`GETFPS5 mm-nn`（mmとnnは0から63までの数字）を実行して下さい。ディスプレイ・アダプターからmmからnnまでのバンク番号のフォントROMデータをダンプします。1バンクは128キロバイトです。例えば、768キロバイト（6メガビット）のフォントROMを全てダンプするには`GETFPS5 0-5`を実行します。

ダンプされたフォントROMデータはDUMPというファイル名で出力されます。

#### GETK55

マルチステーション5550およびPS/55（モデル5530-G, H, 5540-M, P, 5550-M, P, 5560-M, P）で動作すると思いますが、実機での動作は未確認です。

DOSプロンプトで`GETK55 mm-nn`（mmとnnは0から15までの数字）を実行して下さい。mmからnnまでのバンク番号のフォントROMデータをダンプします。1バンクは48キロバイトです。
